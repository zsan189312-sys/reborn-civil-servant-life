# 《重生之我是公务员的一生》适龄提示

**本游戏适合 16 周岁以上用户。**

## 提示依据

| 内容 | 情况 |
|---|---|
| 暴力、血腥、恐怖 | 无 |
| 色情、低俗 | 无 |
| 赌博、现金交易 | 无 |
| 违纪与刑事后果的虚构剧情 | 有（警示性呈现，违规必受惩处，不提供规避监督的方法） |
| 社交、交易、用户生成内容 | 无 |

## 说明

本游戏为文字选择型单机游戏，以虚构的职场成长为主题。游戏中的违纪、处分与刑事判决均为**虚构剧情**，用于呈现遵纪守法的价值导向，不指向任何真实机构或个人，也不构成现实制度或统计说明。

游戏需要理解职场关系与规则边界，建议具备一定社会经验的玩家游玩。

## 未成年人提示

- 未成年人应在监护人同意与指导下游戏。
- 请合理安排游戏时间，避免沉迷。
- 游戏开始画面已登载《健康游戏忠告》。
