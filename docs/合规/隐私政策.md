# 《重生之我是公务员的一生》隐私政策

本游戏为**单机小游戏**。以下说明基于软件的实际行为撰写，与代码实现一致。

## 一、我们收集的信息

**不收集。** 本游戏不收集姓名、手机号、身份证号、位置、通讯录、相册、麦克风、摄像头或任何个人身份信息。无需注册、无需登录。

## 二、我们使用的设备能力

| 能力 | 用途 |
|---|---|
| 屏幕尺寸与安全区 | 界面排版适配 |
| 触摸事件 | 玩家操作 |
| 本地存储 | 保存游戏进度与结局收藏 |

## 三、数据存储与删除

- 游戏进度仅保存在**你的设备本地**，不上传服务器、不联网、不与任何第三方共享。
- 你可以在游戏内选择删除本地数据，也可以直接删除小游戏来清除全部数据。
- 删除后无法恢复，我们会提前提示你确认。

## 四、广告与支付

- 当前版本**不含广告、不含充值、不含任何交易**。
- 将来若接入平台官方广告能力，我们会在接入前更新本政策，并保证广告完全自愿、不打断游戏主线。

## 五、未成年人

- 本游戏含违纪与刑事后果的虚构剧情，建议 16 周岁以上游玩。
- 我们不收集未成年人任何信息。
- 请合理安排游戏时间。
