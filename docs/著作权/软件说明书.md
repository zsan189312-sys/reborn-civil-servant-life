# 《重生之我是公务员的一生》软件说明书

软件全称：重生之我是公务员的一生（游戏软件）
版本号：V1.0

---

## 一、软件概述

本软件是一款**文字选择型单机小游戏**，运行于微信小游戏与抖音小游戏平台。玩家以虚构的县城、省份为背景，从乡镇科员起步，逐年处理具体工作事项、面对利益与责任的选择，并在每年年末接受一次组织评价，体验岗位与职级的成长，最终走向多种结局之一。

剧情、城市与人物均为原创虚构；职务层次与职级名称采用通用表述，不代表现实任免程序。

## 二、运行环境

- 载体：微信小游戏（基础库 3.6.5 及以上）、抖音小游戏
- 设备：Android / iOS 智能手机
- 方向：竖屏
- 联网：**无需联网，无任何网络请求**
- 存储：本地存档（设备本地存储），不上传、不收集个人信息

## 三、主要功能

1. **开局与背景选择**：首屏展示《健康游戏忠告》，玩家选择"前世经历"（决定初始属性，不锁定结局）。
2. **年度经营**：每年一个核心故事，在工作、生活、区域、廉洁考察等类别间轮换；具体事件单局仅出现一次。
3. **事件选择**：每个事件提供 2—3 个选项，选择影响六项属性（能力、政绩、民望、廉洁、家庭、健康）与游戏资金，并写入履历。
4. **人生安排（可选）**：交往、成家、迎接子女、购车、置业、休整等，均可跳过。
5. **晋升风声（可选）**：正常汇报或承担风险的请托选择，不影响客观任免条件。
6. **年终自动评定**：按任职经历、政绩、廉洁、健康与岗位竞争结果，自动作出提拔、留任、职级晋升或降任。
7. **财务账户**：公积金、职业年金余额与流水（纯游戏规则）。
8. **多结局**：9 个主结局（含处分、健康退出、刑事判决等虚构剧情），结局收藏与回看。
9. **本地存档**：进度自动保存，支持继续游戏与重新开始。

## 四、界面与操作流程

1. **启动**：进入首屏 → 阅读《健康游戏忠告》→ 点击"重回录用那一年"或"继续第 N 年"。
2. **前世选择**：三选一，点击"选择"进入新局。
3. **年度档案**：查看身份、任期、六项核心状态、本年主故事入口、可选人生安排与人事动态。
4. **事件页**：阅读正文 → 点击任一选项 → 查看后果与数值变化 → 进入下一年。
5. **年终报告**：查看评分构成与任免结论 → 确认赴任后连续进入新年度剧情。
6. **结局页**：展示结局故事与人生总览，可回看任职履历。

全程触摸点击操作，小屏支持上下滑动查看。

## 五、数据与隐私

- 仅使用设备本地存储保存游戏进度，无网络请求、无账号登录、无第三方共享。
- 可在游戏内删除本地数据。

## 六、内容说明

本作包含利益冲突、违纪与刑事后果的**虚构剧情**，用于呈现选择代价；不提供逃避监督的方法，不美化违法行为。所有数值、概率与任免规则均为游戏参数，不构成现实政策或统计说明。
