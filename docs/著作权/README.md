## 提交时需要的材料（本目录 + 你本人）

1. **源程序**：`源代码.txt`（已按软著格式生成：每 50 行一页、页眉含软件名称+版本号，共 60 页——前 30 页 + 后 30 页）
2. **文档**：`软件说明书.md`（操作说明）
3. **身份证明**：你的身份证扫描件（本人提供）

## 办理要点

- 入口：中国版权保护中心 · 著作权登记系统（`register.ccopyright.com.cn`）
- 费用：软件著作权登记**免费**（国家已停征登记费）
- 周期：普通约 **30 个工作日**；加急需另行选择代办
- 个人名义可申请，**无需营业执照**
- 抖音侧硬性要求：**无软著直接审核驳回**，所以这一步是周期最长的关键路径，**现在就该启动**

## 命名一致提醒（重要，避免返工）

微信官方要求"游戏名称、软著名称、备案名称三者一致"。所以：

- 如果你最终打算**回微信**，软著全称、小程序名称、备案名称要统一口径（例如都用《重生之我是公务员的一生》相关命名）。
- 抖音侧也建议名称一致。
- **定名后先发给平台客服/审核确认**，再提交软著，避免软著办下来名称对不上。
