# 公务员路线内部玩法审计

日期：2026-09-17。当前为内部玩法原型；模拟用于逻辑回归和结局可达性，不代表真人选择、留存、收入、现实任免概率或合规结论。

## 当前基线

- 176 条原型内容：工作 135、生活 26、区域 7、廉洁考察 5、旧存档兼容晋升考察模板 3。新开局不会触发旧模板。
- 每个年度一个主故事，最多 28 年；生活约每 3 年、区域约每 5 年轮入，因果后续和子女节点优先。
- 新流程没有年度申请或追加考察。年末按任职经历、政绩、廉洁、健康、岗位空缺和竞争评价自动调任；“晋升风声”是可跳过的风险选择，不保证晋升。
- 11 个岗位覆盖党政办公室、民政、乡镇政府、市场监管、政法、公安、发展改革、生态环境、交通运输、省政府综合分工和国家层面虚构综合协调岗位。
- 具体事件单局永久限次；普通独立事件另外避开近 3 年的同类语义主题。
- 9 个结局全部可达，包括处分、健康退出、刑事判决与三档虚构有期徒刑责任链。

## 模拟方法与结果

`npm run simulate` 使用 19 种策略、每种 100 个固定种子，共 1,900 局。所有路径从正常开局调用正式引擎，记录事件与选择；结局见证会再次重放。详细数据和源码指纹位于 `artifacts/simulation-audit.json`。

- 9/9 个结局均有正常开局的可重放见证。
- 1,900 局共记录 6,673 次自动职务变化。
- 另用 3,000 局固定种子随机事件选择校准：刑事判决结局 50.23%，较高岗位结局 8.63%。校准策略不主动选择人生安排或“晋升风声”，因此不是全体真人玩家概率。
- 所有策略的单局事件 ID 重复率为 0。
- 没有出现因故事池耗尽而复活旧事件的情况。
- 自动化测试覆盖同 ID 去重、旧存档 `seen` 缺失、当前页旧事件修复、语义主题冷却和因果后续优先。

## 仍未达标

连续三局合并后，跨周目普通内容重复率仍然偏高：

| 策略 | 三局普通抽取 | 不同事件 | 重复率 |
|---|---:|---:|---:|
| 第一选项 | 70 | 45 | 35.7% |
| 随机 | 66 | 46 | 30.3% |
| 平衡 | 73 | 46 | 37.0% |

这不影响“同一局不重播”，但说明玩家重开第二、第三局仍会遇到部分旧故事，尚未达到 PRD 低于 30% 的复玩目标。语义冷却减少相邻年份雷同感，却不能替代继续扩充内容。

## 风险与下一步

1. 新增两批共 32 条口语化跨部门小剧场，覆盖农业农村、市场监管、公安、发改、生态、交通、自然资源、水利、林业、商务、科技、数据、审计、人社、教育和卫生等题材；仍需双人编辑、法律语境和平台分级人工复核。
2. 违法或违纪选择只呈现诱因、短期得失和责任后果；不得增加规避调查、销毁证据或操控具体案件的方法。
3. 多部门调任路线是压缩玩法。公安等岗位默认已履行必要资格与任职程序，不能宣传为现实职业路径教学。
4. 自动策略不执行全部可选人生安排或“晋升风声”；婚育、住房、账户和关系运作有独立流程测试，不代表这些可选系统的真人平衡已经完成。
5. 176 条内容已超过数量目标，但三局复玩重复率仍高于 30% 目标；下一步优先补跨年人物线并邀请真人内部试玩，观察前 10 分钟节奏、重复感和选择吸引力。
6. `npm run check` 会列出 14 条工作/区域事件：它们的 `roleLevels` 写到 7—10 级，但 id 不在高岗位白名单（`province_ / national_ / duty_ / dept_`）内，因此在省级及以上岗位永远不会被抽到。这是数据与规则不一致造成的“已创作但抽不到”，需要一次内容决定：收窄 `roleLevels`，或把这些题材（巡视、审计、匿名举报、直播外泄等）明确纳入高岗位内容池。当前行为未改动。
7. 微信开发者工具和苹果、安卓真机回归仍要重跑；公开发布与广告变现继续受 G0—G7 合规闸门约束。
