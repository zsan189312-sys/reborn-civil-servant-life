# 上架执行清单

所有方框均有可验证证据后，才能提交公开版本。

配套文件：可复现上传步骤见 `RELEASE_RUNBOOK.md`；可直接改用的发布介绍、截图清单、审核说明、自审要点与隐私草稿见 `LAUNCH-MATERIALS.md`。

## 主体、名称与权利

- [ ] 小游戏主体身份和服务类目与实际内容一致
- [ ] 微信后台名称可注册
- [ ] 完成商标相同和近似检索
- [ ] 软著、平台登记、备案/审批和游戏内名称一致
- [ ] 代码、字体、音乐、音效、图片、插件均有权属记录
- [ ] 未使用竞品文案、界面、素材、数据或宣传截图

## 行政与平台材料

- [ ] 已确认并取得本项目所需的游戏审批、备案或证明
- [ ] APP 备案完成，编号展示位置正确
- [ ] 平台要求的自审报告、承诺书和其他材料真实完整
- [ ] 适龄提示、实名与防沉迷按提交时要求接入
- [ ] 客服、投诉、纠纷处理和未成年人监护渠道可用

## 隐私与安全

- [ ] 后台隐私申报与代码实际调用一致
- [ ] 非必要授权被拒绝时仍可玩基础内容
- [ ] 隐私政策包含目的、范围、期限、第三方、删除与投诉方式
- [ ] 数据删除和撤回同意经过真机验证
- [ ] 生产密钥未进入客户端仓库
- [ ] 依赖、云函数、存档篡改和异常恢复测试通过

## 内容与体验

- [ ] 160 条事件和 9 个主结局完成双人复核；处分、刑事判决及三档虚构刑期另做法律语境复核
- [ ] 允许公务员、县长等通用称谓和真实职务层次；具体城市人物虚构，不冒充真实机关/领导，不作现实政策效果承诺，不仿官方证明与标识
- [ ] 职务与职级分开呈现；任免、薪资、年限等游戏规则不冒充现实制度
- [ ] 不美化违法、腐败、欺诈、赌博或其他违规行为
- [ ] 首三局普通事件重复率小于 30%
- [ ] 低端 Android、主流 iPhone 和常见屏幕比例真机通过
- [ ] 前后台切换、断网、来电、存储不足等异常场景通过

## 广告与发布

- [ ] 仅使用微信批准的广告能力和广告位

- [ ] 未成年人广告限制验证通过
- [ ] 广告素材投诉和紧急关闭流程演练完成
- [ ] 首发版本、审核版本与线上代码内容一致
- [ ] 已准备 5%、20%、50%、100% 分阶段放量和回滚方案
