## 解锁后的执行顺序（拿到正式 AppID 之后）

1. **你**：把正式 AppID 填进 `project.config.json` 的 `appid`
2. **我**：跑 `npm run check` + `npm run simulate`，确认提交包内容干净
3. **你**：开发者工具里打开仓库 → 详情 → 本地设置 → 确认调试器 Console **无网络请求、无隐私接口调用**
4. **你**：真机调试，按上面「仍未验证」清单逐项过一遍
5. **你**：上传（填版本号与改动备注）→ 微信公众平台提交审核
6. **你 + 我**：审核前把实际内容与材料过一遍（`LAUNCH-MATERIALS.md` 里的介绍、截图、审核说明、自审要点、隐私说明）
7. **你**：签署承诺、支付费用、灰度放量（5% → 20% → 50% → 100%）与回滚准备

第 5 步之后才叫「提交审核」；审核通过并发布之后才叫「上线」。**在此之前我不会说已经上线。**

- 主体、类目与实际内容不一致
- 用测试号或非本人账号发布

- 隐藏功能、错选类目、用普通小程序类目套壳
- 未取得平台要求的审批/备案就公开运营
- 接了假广告位，或广告打断主线、非自愿、无每日封顶
