# G0：个人主体与小游戏账号核验

这一步必须在继续扩充正式内容、申请软著或接广告之前完成。它需要开发者本人登录微信公众平台，Codex 不应接触身份证照片、银行卡、短信验证码或登录密码。

## 需要确认的账号事实

- [ ] 已注册的是“微信小游戏”账号，而不是用普通小程序类目承载游戏；
- [ ] 主体类型显示为“个人”，实名认证信息正确；
- [ ] 后台允许选择与本作相符的游戏类目；
- [ ] 后台列出的发布材料已经逐项保存到本人的合规档案；
- [ ] 已确认小游戏 APP 备案入口和当前办理状态；
- [ ] 已确认平台对游戏出版审批、备案或其他证明文件的具体要求；
- [ ] 已确认个人主体能否开通流量主、当前门槛、结算主体与税务处理；
- [ ] 已确认未成年人实名、防沉迷和适龄提示的接入要求。

> 我是中国大陆个人主体，拟开发名为《重生之我是公务员的一生》的微信小游戏。城市、人物与剧情均为原创虚构，使用科员、副镇长、县级部门负责人、副县长、省级部门负责人、副省长和党委书记、副书记等通用职务称谓，并区分领导职务与职级；国家层面只设置明确标注为虚构且不对应现实机构的综合协调岗位。玩法是文字事件选择、属性成长、模拟提拔/调任和多结局；不冒充真实机关或领导，不制作仿官方文件，不声称游戏规则是现实任免制度，不提供充值、抽卡、交易、红包或社交，仅计划在平台允许后使用微信官方激励视频广告。请基于上述实际题材书面确认：1）个人主体能否发布、应选类目及该题材内容限制；2）首次发布需要提交的软著、游戏出版审批/备案或其他证明；3）APP 备案流程；4）实名、防沉迷和适龄提示要求；5）个人主体流量主开通、结算和税务所需材料。若不同环节由不同团队负责，请分别给出官方办理入口。

## 需要留存的证据

保存在开发者本人控制的安全位置，不提交到 Git：

- 账号主体和类目页面截图；
- 客服工单编号、完整问答和日期；
- APP 备案、游戏相关备案/审批的受理和结果文件；
- 软著证书、名称检索和素材授权；
- 广告能力开通页面、结算协议和纳税记录。

只需提供以下信息，不要提供证件或密码：

- 是否已经拥有小游戏 AppID；
- 微信后台显示的主体类型和可选类目文字；
- 平台要求的材料名称；
- 工单答复的非敏感正文；
- 是否已经安装微信开发者工具。
