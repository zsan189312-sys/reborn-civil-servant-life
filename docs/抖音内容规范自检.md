# 抖音小游戏内容规范 · 逐条自检报告

对照《抖音小游戏内容规范》（developer.open-douyin.com/docs/resource/zh-CN/mini-game/operation1/norms/content-norms-for-mini-game，更新于 2025-06-09）与《重生之我是公务员的一生》实际代码与文案，逐条核对。扫描方式：对 `src/` 全部源码做关键词与条款比对。

## 结论

- **12 大类中 10 类完全干净**；2 类存在**待补齐的硬项**（信息标识、适龄/防沉迷），1 类属于**审核员主观判断区间**（违规题材的呈现方式）。
- **内容本身没有硬性违规**：无赌博、色情、暴力血腥、封建迷信、现金奖励、用户自定义上传、抽奖、真实地图与国旗元素。
- **但"能不能过审"由审核员判断，本报告不能替代平台结论。**

## 待补齐清单（按依赖顺序）

1. **软著**：本作提审的硬门槛，材料已备好（`docs/著作权/`），需本人提交。下发后回填著作权登记号到开始画面。
2. **适龄提示**：需确定适龄级别（本作含违纪/刑事虚构情节，建议按平台标准评估，倾向 12+ 或 16+，**以平台标准为准**）。
3. **未成年人防沉迷**：按平台提供的接入方式实现。
4. **首屏隐私弹窗**：本作不收集任何个人信息，文案应如实写"不收集、仅本地存储"。

## 关于 2.8 的说明（建议附在提审"审核说明"里）

> 本作为文字选择型廉政警示题材：玩家面对请托、礼金等违规选项时，游戏如实呈现其代价——核查风险累积、处分乃至刑事判决，且**不提供任何规避监督、隐匿证据或干扰案件的方法**；同时设有多条坚守底线的正面结局。内容为纯虚构，不指向任何真实机构或个人，旨在呈现遵纪守法的价值导向。

## 风险声明

- 本报告基于**当前代码与文案**的关键词与条款比对，能排除硬性违规，**不能预测审核员的主观判断**。
- 题材涉及公职与廉政，属于相对敏感区间；是否通过以抖音平台审核结论为准。
