# 抖音小游戏：可行性与上线路径

日期：2026-09-17

## 一句话结论

**对"没有非个人主体"的你，抖音小游戏是比微信更现实的路径**：抖音开放平台官方 FAQ 明确——**个人开发者可以入驻并创建小游戏**，主体验证只需【手机号实名认证】或【银行账户实名认证】二选一，**不需要营业执照**，每个个人主体可创建 25 个小游戏。

---

## 一、为什么抖音个人主体能绕开微信那道坎

| 维度 | 微信个人主体 | 抖音个人主体 |
|---|---|---|
| 能否做小游戏 | 能注册，但**类目受限**（禁文化互动/角色类/牌类） | **能**（官方 FAQ 明确） |
| 需不需要营业执照 | 个人主体不需要 | **不需要** |
| 主体验证 | 个人实名 | 手机号三要素实名 或 银行账户实名（二选一） |
| 可创建数量 | 每微信号最多 5 个 | 每个个人主体 25 个 |
| 本作题材 | 撞「角色类」禁区，走不通 | **未见「角色类」禁令**，待题材过审确认 |

**注意**：抖音个人主体的限制集中在「棋牌、捕鱼、博彩」等特殊类目（个人无法上架，仅企业可做）。文字剧情/角色扮演类不在其列，但仍需**题材过审**（见下）。

---

## 二、仍需做的三件事（不因换平台而消失）

1. **软件著作权（硬性）**：抖音无软著直接审核驳回。个人名义可申请；普通免费约 30—60 个工作日，加急几百—上千元、10—15 天出证。一次办理长期有效。
2. **ICP / 小程序备案**：抖音同样要求完成备案。本作无后端、无网络请求，备案是否需要域名/服务器以平台要求为准。
3. **题材过审确认**：本作含公务员、违纪、刑事等题材。**抖音对政务/敏感题材审核严格**，入驻前应先在开发者平台或客服侧确认该题材能否过审，别等软著办完才发现题材被卡。

## 三、变现

- 抖音个人主体**仅支持广告变现**（穿山甲广告分成，上线即开通、无门槛），**不支持内购/充值**。
- 现有代码**没有任何广告代码**，这是对的。将来接入穿山甲时需新增广告模块，保持**自愿、奖励明确、不打断主线**。

## 四、技术：已做双平台适配（本轮完成）

架构上平台差异只在一个薄层（`src/platform/wechat.js`，约 130 行），引擎、数据、UI 全部复用。本轮改动：

1. `game.js`：入口同时识别 `wx` 或 `tt`，用哪个由运行环境决定
2. `src/platform/wechat.js`：`getWx()` 在 `wx` 不存在时回退到 `tt`（两平台同名 API：窗口信息、本地存档、触摸、前后台生命周期）
3. 新增 `tests/douyin-platform.test.js`：验证「仅存在 tt」时窗口信息、存档读写清除、以及「wx 优先」都正确

**尚未验证**（必须在抖音开发者工具 + 真机做）：`tt.*` 各 API 的实机行为、抖音胶囊安全区、抖音真机性能、抖音端存档与前后台。浏览器模拟与微信侧自动测试不能冒充抖音真机验收。

## 五、如何在抖音跑起来

1. 下载**抖音开发者工具**（字节跳动开发者工具）
2. 实名入驻抖音开放平台（个人身份，手机号三要素认证）
3. 后台创建小游戏 → 获取抖音 **AppID**
4. 开发者工具导入本仓库目录（入口 `game.js` 已兼容 `tt`）
5. 补齐软著、备案、自审报告、隐私协议、适龄提示
6. 提交审核（个人休闲游戏参考 1—3 个工作日出结果）

## 六、与微信的权衡

- **先发抖音会失去微信"首发新游"资格**（微信政策：在其他平台先发过再搬来微信，不算首发，激励金档次下降）。但你现在微信本来就发不了，所以现阶段这不是损失，而是"至少先在一个平台跑起来"。
- 将来若办了主体、想回微信，代码已经双适配，只需换 AppID 与配置，**不需要重做**。

## 七、仍需要你本人完成的事

- 实名入驻（手机号/银行卡实名）
- 软著申请（个人名义）
- ICP / 小程序备案
- 题材与内容过审确认
- 抖音开发者工具 + 真机验收
- 穿山甲广告接入（通过流量主审核后）

## 八、信息可信度

- **高可信（官方 FAQ，developer.open-douyin.com）**：个人开发者可创建小游戏；主体验证方式；可创建数量；企业认证免费；主体类型入驻后不支持变更。
- **中可信（第三方整理）**：软著为硬性要求、软著周期与费用、审核 1—3 个工作日、穿山甲分成比例。
- **需自行核实**：题材能否过审、备案具体要求、广告分成与结算细则。
